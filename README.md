# NAVER 뉴스 자동 분석 (News_analytics.py)

hwp 원본 기획서(`NAVER 뉴스 분석.hwp`) 내용을 기반으로 제작된 자동 분석 프로그램입니다.

## 1. 기능 요약

- 대상 언론사: 조선일보, 문화일보, **매일신문**, 데일리안, 아시아경제 (`News_analytics.py` 상단 `PRESS_LIST`에서 자유롭게 수정)
  - `PRESS_LIST` 의 이름은 **네이버 뉴스 제휴 언론사(87곳)의 등재명과 정확히 같아야** 합니다.
    한 글자만 달라도 oid 조회에 실패해 그 언론사만 결과가 통째로 비게 됩니다.
    (초기 설정의 "매일일보"는 네이버 제휴사가 아니어서 조회에 실패했습니다 — 등재명은 "매일신문")
  - 이름을 못 찾으면 실행 로그에 `비슷한 이름: 매일신문(088), 매일경제(009) ...` 형태로
    후보를 함께 출력하므로, 그 이름으로 고쳐 주시면 됩니다.
- 대상 카테고리(총 8개): 주요뉴스(홈), 이슈(랭킹), 정치, 경제, 사회, 문화, 세계, IT과학 (`CATEGORIES`에서 수정)
- 언론사 × 카테고리별로 당일 기사 **제목 + 본문**(상세 페이지 `#dic_area`, `fetch_article_text()`)을
  함께 수집 → 명사만 추출(kiwipiepy) → **불용어(STOPWORDS) 제거** → 상위 100개 빈도 집계
  (본문 수집을 끄고 제목만으로 빠르게 돌리려면 `--no-fulltext` 옵션 사용 — 3번 항목 참고)
- 불용어 제거는 막대그래프·워드클라우드 두 결과물에 동일하게 반영됩니다(공통 전처리 단계이기
  때문 — 자세한 목록과 커스터마이징 방법은 8번 항목 참고)
- **그래프 4종을 두 단위로 저장** (자세한 내용은 1-1항)
  - 신문사 × 카테고리 단위 → `News/{YYYY}/{MM}/{DD}/{신문사}/{카테고리}/`
  - 일 단위 종합(전 신문사 × 전 카테고리 합산) → `News/{YYYY}/{MM}/{DD}/`
- **인사이트는 CSV로 저장** (엑셀/BI 도구에서 바로 열람·집계하기 위함) — 폴더별 CSV + 전체 통합 `insight_master.csv`

## 1-1. 시각화 그래프 4종

개별 단위와 일 단위 종합 모두 **같은 4종·같은 규격**으로 생성됩니다.

| # | 그래프 | 내용 | 파일명 |
|---|---|---|---|
| ① | 빈도수 워드클라우드 | 단어 전체 빈도수 기반 | `..._빈도수_wordcloud_{YYYYMMDD}.png` |
| ② | 빈도수 바 차트 | 빈도 기준 **상위 20개** | `..._빈도수_barplot_TOP20_{YYYYMMDD}.png` |
| ③ | 감성분석 워드클라우드 | 긍정/부정을 색으로 구별한 단일 워드클라우드 | `..._감성분석_wordcloud_{YYYYMMDD}.png` |
| ④ | 감성분석 바 차트 | **긍정 Top10 + 부정 Top10 = 총 20개**, 하나의 차트에 양방향 배치 | `..._감성분석_barplot_{YYYYMMDD}.png` |
| ⑤ | 키워드 빈도 CSV | ①② 의 원본 데이터 — 정규화·불용어 처리를 마친 **전체 단어**/빈도/감성 | `..._키워드빈도_{YYYYMMDD}.csv` |
| ⑥ | 감성분석 기초자료 CSV | ③④ 의 원본 데이터 — **감성어만** 추린 빈도·비중·색상값 | `..._감성분석기초자료_{YYYYMMDD}.csv` |

**일 단위 종합 폴더에만 추가로 생기는 것** (신문사×카테고리 폴더에는 없음)

| # | 산출물 | 내용 | 파일명 |
|---|---|---|---|
| ⑦ | 일간 인사이트 리포트 | 사람이 읽는 상세 리포트 (7개 절) | `일간종합_인사이트_{YYYYMMDD}.txt` |
| ⑧ | 일간 인사이트 요약표 | 종합·신문사별·카테고리별·조합별 지표 한 행씩 | `일간종합_인사이트_{YYYYMMDD}.csv` |

**제목(Title) 규칙** — 모든 이미지 상단에 필수로 붙습니다.

```
[날짜] - [신문사 또는 "종합"] - [카테고리 또는 "전체 카테고리"] - [분석 유형]

예) 2026-09-01 - 조선일보 - 경제 - 빈도수 바차트 TOP 20
    2026-09-01 - 종합 - 전체 카테고리 - 감성분석 워드클라우드
```

**감성 색상 테마** — 두 감성 그래프(③④)에 동일하게 적용되며, 각 그룹 안에서
**빈도 1위가 가장 진한 색**, 순위가 내려갈수록 옅어집니다.

| 감성 구분 | 색상 테마 | 코드 |
|---|---|---|
| 긍정 (Positive) | 진한 남청색 ➔ 옅은 청색 | `POS_COLOR_DARK` `#0D2B5C` → `POS_COLOR_LIGHT` `#A8D0F0` |
| 부정 (Negative) | 진한 빨강 ➔ 옅은 빨강 | `NEG_COLOR_DARK` `#7A0A12` → `NEG_COLOR_LIGHT` `#F2A6A6` |

감성 분류는 명사 추출·불용어 제거를 마친 **전처리 결과(Counter)를 그대로 재사용**하므로
추가 수집이나 재파싱이 없습니다. 사전에 없는 단어는 중립으로 보고 감성 그래프에서
제외합니다. 단어 목록은 `News_analytics.py`의 `POSITIVE_WORDS` / `NEGATIVE_WORDS`
집합에 있고, 여기에 단어를 추가/삭제하면 ③④ 양쪽에 즉시 반영됩니다.

```bat
cd /d "G:\내 드라이브\03_데이터분석_실습노트북\News"

```

## 3. 실행 방법

`News_analytics.py`는 News 폴더 안의 `실행파일` 하위 폴더에 있으므로, 아래 명령은
그 `실행파일` 폴더에서 실행합니다 (스크립트가 폰트·출력 경로는 알아서 상위의 News
폴더 기준으로 잡아줍니다 — 7번 항목 참고).

```bat
cd News\실행파일

REM 오늘 날짜 전체 언론사/카테고리 분석 (제목+본문 모두 반영, 기본값)
python News_analytics.py

REM 특정 언론사·카테고리만 테스트
python News_analytics.py --debug --press 조선일보 --category 경제

REM 특정 날짜 재분석 (예: 2026년 8월 30일)
python News_analytics.py --date 20260830

REM 본문 수집 없이 제목만으로 빠르게 실행 (요청 수를 줄이고 싶을 때)
python News_analytics.py --no-fulltext
```

`run_test.bat`(**`실행파일` 폴더 안**)을 더블클릭해도 동일하게 테스트 실행됩니다.
이 배치 파일은 python.exe 를 자동으로 찾고, 자기 자신이 있는 폴더(`%~dp0`)를
기준으로 `News_analytics.py` 를 실행하므로 폴더를 옮겨도 그대로 동작합니다.

## 3-1. 일부만 다시 돌리기 (부분 실행)

한 언론사나 한 카테고리가 빠졌을 때, **전체를 다시 돌릴 필요가 없습니다.**

```bat
REM 매일신문만 다시 분석
python News_analytics.py --press 매일신문

REM 특정 조합만
python News_analytics.py --press 매일신문 --category 경제,사회,IT과학
```

부분 실행이어도 결과가 어긋나지 않도록 두 가지가 보장됩니다.

**① 일간 종합은 항상 그날 전체를 반영합니다.**
이번 실행에 포함되지 않은 조합은 날짜 폴더에 이미 저장된
`..._키워드빈도_*.csv` 에서 읽어와 함께 합산합니다(`load_saved_units`). 실행 로그에
`일간 종합 집계 대상 18조합 (이번 실행 3 + 기존 결과 재사용 15)` 처럼 표시됩니다.
같은 조합이 양쪽에 있으면 **이번 실행 결과**를 씁니다.

**② 인사이트 CSV는 중복이 쌓이지 않습니다.**
`insight_master.csv` 와 폴더별 `..._insight.csv` 는 append 가 아니라
`날짜 + 언론사 + 카테고리` 를 키로 한 **갱신(upsert)** 방식입니다. 같은 조합을
몇 번을 다시 돌려도 조합당 한 행만 남습니다.

## 4. 매일 오전 9시 자동 실행 설정

`실행파일` 폴더의 `install_task_scheduler.bat` 을 더블클릭하세요. Windows 작업
스케줄러에 `NaverNewsAnalytics_0900` 작업이 등록되어 매일 09:00에 자동 실행됩니다.

- 등록 확인: `schtasks /Query /TN "NaverNewsAnalytics_0900"`
- 지금 바로 1회 실행: `schtasks /Run /TN "NaverNewsAnalytics_0900"`
- 등록 해제: News 폴더 최상단의 `uninstall_task_scheduler.bat`

이 프로젝트는 G 드라이브(Google Drive)에 있으므로, 예약된 09:00 시점에 PC 가
켜져 있고 로그인 상태이며 Google Drive 가 마운트되어 있어야 실행됩니다.
등록에 실패하면 배치 파일을 마우스 오른쪽 클릭 → **관리자 권한으로 실행**하세요.

## 5. ⚠️ 최초 실행 전 꼭 확인해 주세요

이 스크립트는 개발 과정에서 **naver.com에 접속이 차단된 환경(Claude 샌드박스)**에서
작성되어, 실제 네이버 페이지에 대한 라이브 크롤링 테스트를 하지 못했습니다.

검증 완료된 부분: 한글 형태소 분석(명사 추출), 막대그래프, 워드클라우드, CSV 저장
로직은 샘플 데이터로 정상 동작을 확인했습니다.

검증되지 않은 부분: 실제 네이버 페이지 HTML 구조(선택자)는 자주 바뀌기 때문에,
**최초 1회는 반드시 아래처럼 직접 실행**하여 기사가 정상적으로 수집되는지 확인해 주세요.

```bat
python News_analytics.py --debug --press 조선일보 --category 경제
```

- 콘솔에 `[조선일보/경제] 기사 N건 수집` 로그가 뜨면 정상입니다.
- `기사 0건` 경고가 뜨면 `News/_debug/` 폴더에 원본 HTML이 저장됩니다.
  이 파일이나 콘솔 로그를 공유해 주시면 선택자를 바로 수정해 드리겠습니다.
- 언론사 고유번호(oid)를 자동으로 못 찾으면 `News_analytics.py`의
  `PRESS_OID_FALLBACK` 딕셔너리에 직접 값을 채워 넣으면 됩니다.
- 같은 체크리스트가 `News_analytics.py` 파일 맨 위 docstring에도 "지금 사용자가
  직접 해야 하는 일"이라는 제목으로 그대로 들어 있으니, 스크립트만 열어봐도
  무엇을 해야 할지 바로 확인할 수 있습니다.

### 5-1. News 폴더의 `ChromeSetup.exe`는 왜 자동 실행되지 않나요?

정상입니다. `News_analytics.py`는 브라우저를 전혀 사용하지 않고 `requests` +
`BeautifulSoup`으로 네이버 페이지의 HTML을 직접 요청·파싱하는 방식으로 동작합니다.
따라서 `ChromeSetup.exe`(Chrome 브라우저 설치 파일)는 이 파이프라인이 실행·제어할
대상이 아니며, 자동 실행 목록에도 포함되어 있지 않습니다. 다른 목적으로 받아두신
설치 파일이라면 그대로 두거나 삭제해도 News 자동화 동작에는 아무 영향이 없습니다.
(참고: 만약 이후에 셀레니움/플레이라이트 기반 크롤러로 바꾸는 경우에는 Chrome이
필요해지지만, 현재 구조에서는 필요하지 않습니다.)

## 6. CSV 컬럼 구조 (insight_master.csv, 폴더별 *_insight.csv 공통)

| 컬럼 | 설명 |
|---|---|
| 날짜 | 분석 대상 날짜 (YYYY-MM-DD) |
| 언론사 | 조선일보 / 문화일보 / ... |
| 카테고리 | 주요뉴스 / 이슈 / 정치 / 경제 / 사회 / 문화 / 세계 / IT과학 |
| 기사수 | 수집된 기사 건수 |
| 상위키워드 | 상위 5개 키워드(빈도) 압축 표기 |
| 인사이트 | 규칙 기반 한 줄 요약 |
| 생성시각 | 실행 시각 |
| 상태 | 성공 / 기사없음 / 실패 |

`날짜 + 언론사 + 카테고리` 가 같은 행은 새 값으로 교체됩니다(3-1항 참고).
따라서 같은 날 여러 번 실행해도 조합당 한 행만 남습니다.

CSV는 `utf-8-sig`로 저장되어 엑셀에서 한글이 깨지지 않고 바로 열립니다.

## 6-1. 키워드 빈도 CSV 스키마 (`..._키워드빈도_{YYYYMMDD}.csv`)

명사 추출(정규화)과 `STOPWORDS` 불용어 제거가 **끝난 뒤의 분석 결과**를 그대로
기록한 파일입니다. 그래프가 그려진 것과 완전히 같은 데이터이므로, 그림에서 읽은
값과 CSV 값이 항상 일치합니다.

| 컬럼 | 설명 |
|---|---|
| 날짜 | 분석 대상 날짜 (YYYY-MM-DD) |
| 구분 | 신문사명 (일 단위 종합 파일은 `종합`) |
| 카테고리 | 카테고리명 (일 단위 종합 파일은 `전체 카테고리`) |
| 순위 | 빈도 내림차순 순위 (1부터) |
| 단어 | 추출된 명사 |
| 빈도수 | 등장 횟수 |
| 감성 | `긍정` / `부정` / `중립` (감성 사전 기준, 사전에 없으면 중립) |

- 신문사 × 카테고리 폴더마다 1개, 일자 폴더에 종합본 1개가 생성됩니다.
- `utf-8-sig` 로 저장되어 엑셀에서 바로 열립니다.
- `insight_master.csv` 가 누적(append)인 것과 달리 이 파일은 **같은 날 다시 실행하면
  덮어씁니다** — 그날의 최종 분석 결과 하나만 남기기 위함입니다.

## 6-2. 감성분석 기초자료 CSV 스키마 (`..._감성분석기초자료_{YYYYMMDD}.csv`)

감성 그래프(③④)를 그리는 데 실제로 쓰인 자료입니다. 감성 사전에 걸린 단어만
담기며(중립어까지 포함된 전체 목록은 6-1의 키워드 빈도 CSV에 있습니다),
그래프에 칠해진 **색상 값까지 그대로** 기록해 그림과 표를 1:1로 대조할 수 있습니다.

| 컬럼 | 설명 |
|---|---|
| 날짜 / 구분 / 카테고리 | 6-1과 동일 |
| 감성 | `긍정` 또는 `부정` |
| 순위 | 같은 감성 그룹 안에서의 빈도 순위 (1부터) |
| 단어 | 감성어 |
| 빈도수 | 등장 횟수 |
| 감성내비중(%) | 같은 감성 그룹의 총빈도 대비 그 단어의 비중 |
| 감성단어수 | 그 감성 그룹의 단어 종수 |
| 감성총빈도 | 그 감성 그룹의 빈도 합계 |
| 워드클라우드_색상 | ③에 칠해진 HEX 색상 (그룹 **전체**에 그라데이션을 펼친 값) |
| 바차트_색상 | ④에 칠해진 HEX 색상 (표시되는 **Top 10**에 그라데이션을 펼친 값, 미표시는 공란) |
| 바차트표시 | ④에 나왔으면 `Y`, 아니면 `N` |

색상 열이 둘인 이유: 워드클라우드는 그룹 전체에, 바 차트는 화면에 나오는 Top 10에
각각 그라데이션을 펼치기 때문에 같은 단어라도 두 그래프의 색이 다를 수 있습니다.
바 차트에서 색 대비를 살리기 위한 의도적인 차이이며, **"빈도 1위 = 가장 진한 색"**
규칙은 양쪽 모두 동일합니다.

**활용 예 — 일자별 긍·부정 추이**

```python
import pandas as pd, glob

files = glob.glob("2026/*/*/일간종합_감성분석기초자료_*.csv")
df = pd.concat([pd.read_csv(f, encoding="utf-8-sig") for f in files])

# 날짜별 긍정/부정 총빈도 추이
df.groupby(["날짜", "감성"])["빈도수"].sum().unstack()
```

## 6-3. 일 단위 인사이트 (`일간종합_인사이트_{YYYYMMDD}.txt` / `.csv`)

신문사×카테고리 단위의 한 줄 인사이트(`insight_master.csv`)보다 한 단계 위에서,
**하루치를 취합해 비교까지 담은** 결과물입니다. 일자 폴더에 함께 생성됩니다.

### TXT 리포트 구성

| 절 | 내용 |
|---|---|
| [1] 분석 개요 | 신문사·카테고리·조합 수, 수집 기사 수, 추출 키워드 종수와 누적 빈도 |
| [2] 오늘의 핵심 키워드 TOP 10 | 빈도와 전체 대비 비중(%) |
| [3] 감성 분석 요약 | 긍정·부정 종수/총빈도, **감성지수**, 대표 긍정어·부정어, 한 줄 해석 |
| [4] 신문사별 요약 | 신문사마다 기사 수·키워드 종수·상위 3개·감성지수 |
| [5] 카테고리별 요약 | 카테고리마다 동일 항목 |
| [6] 전 신문사 공통 키워드 | 모든 신문사에 등장한 키워드 = **오늘의 공통 의제** |
| [7] 단독 키워드 | 한 신문사에서만 등장한 키워드 = **차별 보도 지점** |

[6][7]은 신문사가 2개 이상일 때만 생성됩니다.

**감성지수** = (긍정 총빈도 − 부정 총빈도) ÷ (긍정 + 부정 총빈도) × 100

- `+100`에 가까울수록 긍정 우세, `-100`에 가까울수록 부정 우세, `0`이면 균형
- 감성어가 하나도 없으면 `0.0`

### CSV 요약표 컬럼

한 행이 하나의 분석 단위여서 엑셀 피벗이나 pandas 로 바로 집계할 수 있습니다.

| 컬럼 | 설명 |
|---|---|
| 날짜 | 분석 대상 날짜 |
| 분석단위 | `종합` / `신문사` / `카테고리` / `신문사x카테고리` |
| 대상 | `전체`, `조선일보`, `경제`, `조선일보/경제` 등 |
| 기사수 / 키워드종수 / 누적빈도 | 규모 지표 |

## 7-1. 배치 파일(.bat)이 실행되지 않을 때

배치 파일 4종(`실행파일\run_test.bat`, `실행파일\install_task_scheduler.bat`,
`uninstall_task_scheduler.bat`, `install_requirements.bat`)은 **반드시
CP949(ANSI)로 저장**되어야 합니다. UTF-8로 저장하면 한글 부분의 바이트가
cmd 창(코드 페이지 949)에서 깨지고 명령 자체가 실행되지 않습니다.
메모장으로 편집한 뒤에는 [다른 이름으로 저장] → 인코딩을 **ANSI** 로 지정하세요.

같은 이유로, 배치 파일 안에서는 `실행파일` 같은 **한글 폴더 이름을 직접 적지
않고** cmd 가 실행 시점에 채워 주는 `%~dp0`(= 그 배치 파일이 있는 폴더)만
사용합니다. 이렇게 하면 경로에 한글·공백(`G:\내 드라이브\...`)이 있어도 안전합니다.

| 증상 | 원인 / 조치 |
|---|---|
| 창이 떴다가 바로 닫힘 | 배치 파일이 UTF-8로 저장된 경우. ANSI(CP949)로 다시 저장 |
| `ModuleNotFoundError: kiwipiepy` / `wordcloud` | `install_requirements.bat` 을 먼저 1회 실행 |
| `python.exe 를 찾지 못했습니다` | Python/Anaconda 가 PATH 에 없음. 배치 파일을 메모장으로 열어 `set "PYTHON_EXE=C:\Anaconda3\python.exe"` 처럼 직접 지정 |
| 지정한 경로를 찾을 수 없습니다 | `run_test.bat` 이 `News_analytics.py` 와 다른 폴더에 있는 경우. 같은 폴더(`실행파일`)에 두세요 |
| 작업 스케줄러 등록 실패 | 배치 파일을 관리자 권한으로 실행 |

## 8. 불용어(STOPWORDS) 처리 — 빈도 분석·워드클라우드 공통 전처리

명사를 추출한 뒤(`extract_noun_counter()`), 아래 성격의 단어는 실제 이슈 키워드가
아니라고 보고 집계에서 제외합니다: 보도체/저작권 관련 표현(기자, 사진, 무단전재,
구독, 댓글 등), 시간 표현(오늘, 지난해, 이번주 등), 보도 상투 표현(발표, 밝혔다,
전했다 등), 범용 추상명사(관계자, 부분, 상황, 문제 등). 목록은 `News_analytics.py`의
`STOPWORDS` 집합에 있으며, 자유롭게 단어를 추가/삭제할 수 있습니다.

이 전처리 결과(불용어가 제거된 `Counter`)를 막대그래프(`save_bar_chart`)와
워드클라우드(`save_wordcloud`) 두 함수가 그대로 전달받아 사용하므로, `STOPWORDS`에
단어를 추가하면 두 시각화 모두에 즉시 반영됩니다. 특정 단어가 계속 상위권에
보이는데 의미 없는 클리셰라면, `STOPWORDS = { ... }` 안에 그 단어를 추가하기만
하면 됩니다.

## 8-1. 감성 사전 커스터마이징

`POSITIVE_WORDS` / `NEGATIVE_WORDS` 는 명사 기준 사전입니다. 분석 결과에서
"이 단어는 부정으로 봐야 하는데 빠졌다" 싶은 것이 보이면 해당 집합에 추가하기만
하면 감성 워드클라우드와 감성 바 차트에 함께 반영됩니다.

주의: `STOPWORDS` 에 들어 있는 단어는 명사 추출 단계에서 이미 제거되므로
감성 사전에 넣어도 잡히지 않습니다(예: `지적`). 감성어로 쓰고 싶다면
`STOPWORDS` 에서 먼저 빼야 합니다.

## 9. 확장 아이디어 (응용)

- ✅ **구현 완료**: 기사 제목뿐 아니라 본문까지 키워드 분석에 반영합니다.
  `fetch_article_text()`가 기사 상세 페이지의 `#dic_area` 선택자로 본문을 가져오고,
  `process_one()`이 이를 제목과 함께 `extract_noun_counter()`에 전달합니다.
  카테고리당 본문을 가져오는 기사 수는 `MAX_ARTICLES_FOR_TEXT`(기본 15건)로
  제한되어 있으며, 필요하면 이 값을 조정하거나 `--no-fulltext`로 아예 끌 수 있습니다.
- `insight_master.csv`는 폴더별로 나뉘지 않고 News 폴더 최상단 파일 하나에 매일
  실행 결과가 계속 이어붙는(append) 구조입니다. 그래서 날짜가 쌓일수록 별도 작업
  없이도 시계열 키워드 트렌드 분석, 언론사 간 이슈 비교로 바로 확장할 수 있습니다.
  예를 들어 아래처럼 pandas로 바로 집계할 수 있습니다:

  ```python
  import pandas as pd

  df = pd.read_csv("insight_master.csv", encoding="utf-8-sig")
  df["날짜"] = pd.to_datetime(df["날짜"])

  # 언론사 × 날짜별 기사수 추이 (시계열 트렌드)
  trend = df.pivot_table(index="날짜", columns="언론사", values="기사수", aggfunc="sum")

  # 특정 키워드가 날짜별로 언론사 간 얼마나 등장했는지 비교하려면
  # 상위키워드 컬럼("'단어'(빈도), ..." 형식)을 파싱해 언론사별로 비교하면 됩니다.
  ```
- 감성분석을 추가하려면 `Oliveyoung_VS_code` 폴더에 이미 사용하신
  `5-4. CJ올리버영_상품리뷰_감성분석.py` 로직을 재활용하실 수 있습니다.

### A-5. ⚠️ 설치 경로 주의

**작업 폴더를 VS Code 설치 폴더(예: `D:\VS_code\`) 안에 두지 마세요.**
VS Code는 자동 업데이트할 때 설치 폴더의 내용을 통째로 교체하므로,
그 안에 있던 사용자 폴더가 **휴지통을 거치지 않고 삭제**됩니다.
설치 경로는 `설정 → 정보` 또는 아래 명령으로 확인할 수 있습니다.

```powershell
Get-ItemProperty "HKCU:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\*" |
  Where-Object DisplayName -like "*Visual Studio Code*" |
  Select-Object DisplayName, InstallLocation
```
